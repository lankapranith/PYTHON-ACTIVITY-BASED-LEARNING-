## Overview

This repository presents the Python Programming ABL work prepared during the Dussehra holidays. It contains 10 Python programs designed to practise important programming concepts, including decision-making, loops, functions, lists, and nested data structures.

6. Employee Payroll and Deduction Review
7. Student Marks Matrix Processing
8. Canteen Ordering and Stock Management System
9. Library Book Borrowing and Fine Calculation
10. Even-or-Odd Number Verification
